# JavaScript Calculator
freecodecamp advanced front end development project

## Tech Stack
- HTML
- CSS
- Bootstrap
- JavaScript
- jQuery

## Instructions
1. Clone or download zip file. 
2. Go to your terminal and cd into calculator directory. 
3. Run ```npm start``` to start the app. 
4. Type numbers and symbols on the calculator. Press the equals button to get your answer.
